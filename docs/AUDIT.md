# NOVA project audit

**Reviewed 18 November 2026**

The review covered the application files, all 24 tool views, Electron and Tauri, the PowerShell and C# launch paths, packaging, CI configuration, tests, and project documentation. The existing portable runtime, bundled assets, logs, icon files, launcher, shortcut, and certificate were inspected as build or release inputs. Dependency packages and generated build trees were inventoried at the directory level.

## Findings and fixes

| Area | Finding | Result |
|---|---|---|
| Desktop island | The collapsed window stayed 720 px wide. Native and renderer offsets stacked. Hover timers and automatic retraction could get out of sync. | The native window now follows the rendered dimensions and work area. Transparent margins pass mouse input through. The collapsed pill can roam while an open panel stays on its display. |
| Desktop security | The renderer had Node access and disabled web security. Launcher actions interpolated input into a PowerShell command. | An isolated, sandboxed preload exposes a limited set of operations. The launcher accepts supported URLs, full paths, and executable names without invoking a command shell. |
| NOVA Drop | The receiver started with the app. The QR was generated by an internet service. An upload could replace a previously received file. | Receiving is user-started, expires after 10 minutes, and uses a locally generated QR. Transfers are limited to 512 MB per file. Duplicate names are preserved with suffixes. |
| Settings | Startup status was optimistic. Clearing Clipboard used a different key from the Clipboard view. | Startup uses the actual Windows login-item result. Clipboard settings and clearing use the app-wide history. |
| Runtime scope | The desktop launcher uses Electron. The repository’s GitHub release workflow targets Tauri, which has a smaller set of native integrations. | The local portable Electron build now has a repeatable command that updates the launcher payload. The Tauri metrics serialization uses the field names the UI expects. |

## Tool review

| Tool | Findings |
|---|---|
| Home | Replaced the dense dashboard with a command entry, six quick actions, media controls, and a system glance. |
| Clipboard | Captures text across the app while enabled. Adds a privacy switch, keeps pinned entries on repeated copy, and removes copied text from the toast. |
| Notes | Removed in-memory sample notes. Notes persist locally and accept scratch notes from the command bar, including older scratch entries. |
| Saved Links | Routes browser launches through the desktop bridge. Better URL validation and editable entries remain useful. |
| Weather | Uses the forecast location’s timestamps and forecast values for rain and UV. Labels sample, saved, and manually entered data. |
| Units & FX | Shares conversion logic with the command bar. Currency conversions are estimates based on built-in rates. |
| NOVA Drop | Session pairing and concurrent same-name writes have regression coverage. Phone scanning and transfer on a real Wi-Fi network are pending. |
| File Shelf | Restores real Windows paths through the current Electron File API. The shelf works as a set of references to original files. |
| File Converter | Selects compatible target formats and avoids restoring dead download links from old conversion history. |
| File Tools | Native file selection passes an actual disk path to the Windows runtime for streaming checksums. |
| Timers & Focus | Uses elapsed wall time, supports command durations such as `timer 90s`, and preserves time extensions. |
| Calendar | Clamps the selected date when moving to a shorter month. Scheduled reminders and calendar import are future work. |
| World Clock | Uses the machine’s timezone for Local time and named zones for regional clocks. |
| Screen Time | Uses sampled foreground and idle time from the current NOVA session. Reliable history across restarts is still needed. |
| System Monitor | Removes hardcoded CPU temperature, frequency, and GPU memory readings. |
| Custom Message | Sends a ticker to the island. Color selection needs to be carried through to the ticker. |
| Quick Launcher | Launches supported targets with Windows feedback. Installed-app discovery and custom icon support are future improvements. |
| Quick Settings | Adds actual brightness controls on displays supported by the Windows brightness interface. Wi-Fi, Bluetooth, and Night light open the corresponding Windows surfaces. |
| AI Coding Monitor | Supports manual entries and optional example data. Automatic provider log imports are future work. |
| Website Analytics | Tracks request reachability and latency. Actual HTTP status and analytics provider metrics are separate integration work. |
| Revenue Dashboard | The monthly goal uses entries from the current month. Entries are recorded manually. |
| Desktop Pet | Existing mascots and progress remain available. A quieter, low-motion state is worth profiling on battery. |
| Customization Studio | Keeps the existing shapes and presets. Theme colors render correctly when no custom override is set. |
| Settings | Groups appearance, Windows, privacy, and keyboard controls. Appearance reset restores the full set of theme defaults. |

## Priorities

| Order | Work | Benefit |
|---|---|---|
| 1 | Ship from one Windows runtime. Add an Electron CI build with clean-install smoke tests, a signed installer, and a versioned portable ZIP. | Everyone downloads the same app that is tested locally. |
| 2 | Measure idle CPU, memory, and battery draw. Replace short-lived PowerShell polling with a small Windows helper where measurements justify it. Add a battery-saving preset and pause decorative effects during fullscreen apps. | NOVA can stay running alongside games and Unreal Engine without unnecessary overhead. |
| 3 | Add a first-run setup with four pinned tools, editable Home shortcuts, and remappable hotkeys. | The island stays easy to learn as the module catalog grows. |
| 4 | Add capabilities to Quick Settings. Show current volume and supported brightness at a glance and support compatible external monitors separately. | Windows integrations become easier to discover and troubleshoot per device. |
| 5 | Add clipboard capture exclusions, retention, and a settings/notes export. Give Screen Time an opt-in persistent history and a clear reset. | Users can control what NOVA stores and move their setup between machines. |
| 6 | Add resumable transfers and explicit device confirmation to Drop. Test phone pairing across private Wi-Fi, Ethernet, hotspots, and Windows Firewall conditions. | Large transfers survive interruptions, and people can tell which device is connected. |
| 7 | Add named appearance presets and per-app behavior, such as a minimal Work layout, compact Gaming layout, and a colorful Creative layout. | Users can switch quickly without navigating individual sliders. |

## Verification

- Automated regression tests cover window bounds, command math and conversions, timer timing, and Drop session creation, port fallback, and duplicate filenames.
- The isolated Electron smoke test opened the real Windows renderer and exercised collapsed/expanded sizing, the isolated bridge, the command bar, note creation, and navigation through Settings and Quick Settings.
- Physical display brightness, actual phone pairing, real multi-monitor transitions, higher-DPI layouts, Windows login persistence, and the first run on a clean Windows installation remain hands-on checks.
